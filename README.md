An uncluttered window into make.fun: browse and filter live bounties, read challenge rules, compare entrants on paginated leaderboards, and explore public builder profiles and their solutions. The app uses small static HTML, CSS and vanilla JavaScript files with no build step, dependencies or sign-in. Public GET responses are cached in memory and revalidated with ETags.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in your browser.
